# 高山流水 · 遇知音 🏔️

> 2 分钟，用金句遇见你灵魂里的知音。

选 5 句最戳心的金句，测出你的古典知音人格（12 张人格卡 + 2 张隐藏彩蛋卡），生成专属分享海报。

## ✨ 功能

- 🎼 **金句选句测试**：5 轮 × 6 句，2 分钟完成
- 🏔️ **12+2 古典知音人格**：伯牙 / 钟子期 / 庄子 / 李白 / 苏轼 / 王维 / 嵇康 / 陶渊明 / 辛弃疾 / 王阳明 / 林黛玉 / 孟子 + 隐藏（老子 / 孔子）
- 🖼️ **分享海报**：Canvas 生成 1080×1440 竖版海报（抖音快手 3:4 兼容）
- 🎐 **今日一签**：一言免费 API + 本地兜底
- 🎲 **随缘选句**：选择困难症友好
- 🧪 **调试模式**：`?debug=1` 可预览全部人格卡

## 🚀 运行

```bash
# 本地（直接双击 index.html 即可，或用任意静态服务器）
npx serve .

# 测试
node tests/logic.test.js
```

在线体验：<https://tangwenqing123.github.io/gaoshan-liushui/>

## 🗂️ 目录结构

```
├── index.html
├── css/style.css            # 设计令牌：治愈系 + 玻璃拟态 + 国风
├── js/
│   ├── data/personas.js     # 12+2 人格卡配置
│   ├── data/quotes.js       # 40 句金句题库（含人格权重）
│   ├── engine.js            # 选句/计分/隐藏卡引擎（可单测）
│   ├── quote.js             # 每日一签（一言 API + 兜底）
│   ├── poster.js            # Canvas 海报
│   ├── result.js            # 结果页渲染
│   └── app.js               # 主控/路由/埋点
├── tests/logic.test.js      # 单元测试（15 用例）
└── docs/                    # 立项 + 技术设计文档
```

## 📈 数据（v1 匿名埋点）
