## 一、项目概述

**一句话定位**：一个「**金句选句 → 人格结果**」的轻心理测试产品，2 分钟出结果，结果即"人格卡 + 专属金句 + 分享海报"。

- 产品形态：网页版（MVP）→ 微信小程序（第二阶段）
- 项目性质：三重角色合一
  1. **学习载体**：作为"每日一小工具·能力阶梯"的第 1 阶，后续逐级累加技术栈
  2. **引流产品**：为工作室（AI Agent/RAG 接单）沉淀流量与个人 IP
  3. **数据资产**：通过互动数据沉淀自建金句库 + 用户行为库，形成壁垒

## 二、背景与市场机会

### 2.1 市场数据（调研结论）
- 全球心理测验市场预计 2032 年达 **78.21 亿美元**，持续增长
- 对话式心理健康 App 为增长最快细分赛道
- 中国行业趋势：**规范化、智能化、普惠化**
- AIGC App 月活一年净增超 2 亿，AI 化是主旋律

### 2.2 爆款验证（需求真实存在）
| 案例 | 验证点 |
|------|--------|
| **SBTI 人格测试**（2026.4 刷屏） | "短选项 + 玩梗结果文案" = 百万流量，人人截图分享 |
| **16Personalities** | 全球最火免费人格测试，结果页结构专业 |
| **人生重开模拟器** | 选择向 + 游戏化 + 重玩欲 = 一夜爆红 |
| **腾讯职场人设 H5** | 大厂验证的选择式测试交互 |

### 2.3 用户痛点（体验竞品后总结）
1. **太长了** —— 传统测试 60+ 题，中途放弃率高
2. **内容重复** —— 同类测试同质化严重
3. **没有结果感** —— 测完无收获、无记忆点、无分享欲

### 2.4 技术红利
- **免费金句 API（一言 hitokoto）**：已实测可用，无需 key，金句冷启动零成本 ✅
- **低成本大模型（DeepSeek）**：一次 AI 解读成本约几分钱，按量收费利润空间大

## 三、产品定位

- **定位语**：*2 分钟，用金句遇见真实的自己*
- **差异化四板斧**：
  1. **短**：5~6 轮选句，2 分钟出结果
  2. **结果感强**：人格卡 + 专属金句 + 巴纳姆式解读 + 分享海报
  3. **游戏化**：集卡（含隐藏卡）、每日一签、分享解锁
  4. **AI 升级**（后续）：DeepSeek 解读选句逻辑 + 个性化建议
- **边界声明**：定位**自我探索/娱乐向**，不做医疗诊断、不做心理咨询（合规红线）

## 六、MVP 功能范围（v1）

### ✅ v1 包含（本期必须）
1. **金句选择测试**：5 轮 × 每轮 4~6 句金句，选最戳心的一句
2. **12 种人格卡**：如「孤独诗人 / 清醒旁观者 / 温柔救赎者 / 自由灵魂 / 理性建筑师 / 冒险家……」+ 2 张隐藏卡
3. **结果页**：人格卡 + 专属结果金句 + 巴纳姆式解读（"准到吓人"文案）+ 分享按钮
4. **分享海报**：Canvas 生成可保存图片（人格卡 + 金句 + 二维码/官网链接）
5. **每日一签**：接入一言免费 API（哲学/文学分类）
6. **免责声明 + 隐私说明**：非医疗声明、匿名化承诺
7. **再测/重玩**：一键重测（游戏化钩子）

### ❌ v1 不做（排期 v2+）
- 用户登录、后端存储（v3）
- AI 解读、付费（v5/v7）
- 小程序、社区、内容库（后续）

## 七、核心用户流程

```
首页（钩子金句 + "开始测试"）
   ↓
第 1~5 轮：每轮展示 4~6 句金句 → 选 1 句（进度条提示"第 3/5 轮"）
   ↓
结果页：人格卡动画揭晓 → 专属金句 → 性格解读（3~4 段）
   ↓
行动：① 生成分享海报  ② 再测一次  ③ 每日一签  ④ (v2)收藏
```

## 十一、商业模型（免费增值 + 按量计费）

```
免费层（边际成本≈0）         付费层（产生 API 成本时收费）
├── 金句浏览/每日一签         ├── AI 深度解读（单次 1~3 元 / 次数包 / 会员）
├── 金句人格测试（全流程）     ├── AI 陪伴对话（长对话按量）
├── 人格卡 + 分享海报          └── 高级功能（无限测/隐藏卡/去广告）
└── 引流到公众号/私域 → 工作室接单（主变现路径）
```

**成本结构**：前期≈0（静态 + 免费 API）；AI 阶段 DeepSeek 约几分钱/次。
**变现优先级**：① 引流接单（主业）② AI 解读小额收入 ③ 后期会员/广告。

## 十三、风险与合规

| 风险 | 应对 |
|------|------|
| 医疗合规 | 全程"自我探索/娱乐"定位 + 免责声明，禁"诊断/治疗"措辞 |
| 数据合规（PIPL） | 测试结果匿名化、最小收集、隐私政策，v1 不收集身份信息 |
| 诱导分享红线 | 不强制分享、不"分享才能看结果"（网易云颜色测试被屏蔽的教训） |
| 支付资质 | 个人主体无法开微信支付 → 收费需个体户/企业主体（收费前办理） |
| 一言 API 稳定性 | 前端缓存 + v2 起自建金句库兜底 |
| GitHub Pages 国内访问慢 | 后续切 Cloudflare Pages / CloudBase |
