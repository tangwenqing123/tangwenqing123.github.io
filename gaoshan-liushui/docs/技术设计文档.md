## 1. 技术选型与理由

### v1（本期，静态版）
| 选型 | 选择 | 理由 |
|------|------|------|
| 前端 | 纯 HTML + CSS + JS（SPA-lite 多视图切换） | 零构建、当天可上线、GitHub Pages 直出 |
| 数据 | 本地 JSON 文件（quotes.json / personas.json） | 免后端、免数据库，内容即代码 |
| 金句 API | 一言 hitokoto（v1.hitokoto.cn） | 免费无 key、已实测可用、支持 CORS |
| 海报 | Canvas 2D 原生绘制 | 零依赖；html2canvas（CDN）作兜底 |
| 分享 | Web Share API + 海报下载 | 移动端原生分享；下载保底 |
| 部署 | GitHub Pages（`tangwenqing123.github.io/gaoshan-liushui/`） | 免费、现有账号已授权 |
| 埋点 | 自研 localStorage 计数（v1）→ 后续接分析平台 | 轻量起步 |

### 演进路径（能力阶梯映射）
```
v1 静态版（R1）→ Vite 工程化（R4）→ FastAPI + Supabase（R5-R6）
→ 用户系统（R7）→ 部署公网（R8）→ DeepSeek AI 解读（R9）→ RAG（R10）→ 小程序（R12）
```

## 4. 核心数据结构

### 4.1 人格卡 personas.json（12 位古典知音原型 + 2 隐藏）

```json
{
  "id": "boya",
  "name": "伯牙",
  "title": "琴心洞察者",
  "emoji": "🎼",
  "allusion": "伯牙善鼓琴，高山流水，知音难觅",
  "quote": "相识满天下，知心能几人",
  "dimensions": { "理性": 5, "感性": 3, "自由": 2, "内敛": 4 },
  "colors": ["#2f6f8f", "#5ba8c9"],
  "desc": ["你像伯牙一样，外表从容，内心却有自己的一方天地……"],
  "strengths": ["洞察力强", "情感深沉", "专注深耕"],
  "advice": "你的知音不在多，而在真。学会偶尔把琴声说给人听。"
}
```

12 人格（暂定）：伯牙·琴心洞察者 / 钟子期·知音共情者 / 庄子·逍遥行者 / 李白·谪仙浪漫者 / 苏轼·豁达乐天者 / 王维·山水静观者 / 嵇康·竹林自由者 / 陶渊明·采菊归隐者 / 辛弃疾·铁血柔情者 / 王阳明·知行合一者 / 林黛玉·绛珠敏感者 / 孟子·浩然热血者
2 隐藏：老子·道法自然者 / 孔子·温良善学者（彩蛋触发）

### 4.2 金句题库 quotes.json

```json
{
  "id": "q001",
  "text": "相识满天下，知心能几人",
  "author": "《增广贤文》",
  "category": "知音",
  "weights": { "boya": 2, "zhongziqi": 3 },
  "mood": "孤高"
}
```

- 总量：**30+ 句**（每轮 6 句 × 5 轮，且轮内不重复）
- 每句绑定 2~3 个人格权重（+1~+3），驱动计分
- 分类：知音 / 孤独 / 治愈 / 成长 / 自由 / 热爱

### 4.3 计分与匹配算法（test.js）

```
1. 每轮从题库随机抽 6 句（全局不重复），展示供选择
2. 选中某句 → 累加该句 weights 到各人格维度分
3. 5 轮结束 → 总分最高人格 = 主结果
4. 平票 → 按维度优先级（感性>理性>自由>内敛）破平
5. 隐藏卡触发：
   - 庄子·逍遥：5 轮中 ≥3 次选择 category="自由" 的金句
   - 老子·道法：随机彩蛋（<10% 概率）+ 首次完成
6. 结果文案 = 人格卡模板 + 用户选择痕迹插值（巴纳姆效应文案）
```

### 4.4 每日一签（quote.js）

```
1. 优先请求 v1.hitokoto.cn/?c=k（哲学）或 c=d（文学）
2. 成功 → 展示 + 缓存到 localStorage（今日 key，防重复请求）
3. 失败/超时 → 从本地 quotes.json 兜底随机一句
4. 缓存 TTL = 当日 24:00 失效
```

## 11. 风险与技术债

| 风险 | 应对 |
|------|------|
| 一言 API 波动 | 前端缓存 + 本地题库兜底 |
| 海报在微信内置浏览器兼容 | 真机专项测试；兜底方案 html2canvas CDN |

| 题库轮内重复/倾斜 | 抽题算法保证全局不重复 + 权重平衡校验 |
| 抖音快手内容生产 | 预留竖版海报/演示视频模板（运营文档另行规划） |
